Three states of the use

State 0 is before the practice, state τ is after the practice with the freed water unused, and state 1 is after the freed water goes to its destinations. The last column is −ΔτX = X0 − Xτ; its totals are Fwet and F.

Model and assumptions

The tool evaluates the paper's equations for one use and one diversion.

  • Partition. W = C_b + C_n + N + R. Each physical path (the quick path and the slow path) counts as recoverable return R or as non-recoverable outflow N, according to the setting.
  • Freed water. F = −ΔτW, F_wet = −ΔτD, F_dry = −ΔτR, where Δτ is the change from state 0 to state τ.
  • Type. A if the practice cuts beneficial consumption (ΔτCb below −5% of F), otherwise B if the wet part is larger and C if the dry part is larger; D if F is near zero.
  • Fate. ΔD = −F_wet + F·Σ λᵢ dᵢ and φ = −ΔD / F, with d_s = 0.
  • Rebound. Re-applied water uses the post-practice technology, so d_u = D^τ / W^τ and its returns split the same way.
  • Transfer. The new user depletes d_t and returns the rest on the quick path.
  • Banking. Banked water loses d_b to evaporation and recharges the aquifer with the rest, which returns on the slow-path schedule.
  • Shared diversion. Re-applied, transferred, and banked water all pass through the original diversion, so observed withdrawal falls only by the protected share.
  • Timing. A steady annual cycle. Diversions follow a monthly profile, quick returns arrive in the same month, and slow returns follow an exponential lag with the mean set above. Over a year, node B sums to −ΔD; node A does not.

The examples use the paper's 100-unit district and reproduce its scenario table: fallowing gives φ = 0.45, modernization into trust gives 0.06, and modernization with rebound gives −0.78.
